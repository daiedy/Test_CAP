# Тексты и переводы

## Файлы
- `_i18n/i18n.properties` (en, по умолчанию) и `_i18n/i18n_ru.properties`: labels модели, ключи `<Entity>.<element>` и `<Entity>` для имени сущности.
- `_i18n/messages.properties` и `_i18n/messages_ru.properties`: сообщения `req.reject`, ключи UPPER_SNAKE: `PRODUCT_STOCK_NEGATIVE`.
- `app/<app>/webapp/i18n/i18n.properties` и `i18n_ru.properties`: тексты приложения, ключи `<page>.<element>.<property>`, плюс `appTitle`, `appDescription`.

## Правила
- Любой новый ключ добавляется сразу в обе локали (en и ru). Пустых переводов нет.
- Ключи не переименовывать без поиска по репозиторию (`grep -r '<key>'`).
- Плейсхолдеры `{0}`, `{1}` для аргументов `req.reject(400, 'KEY', [a, b])`.
- Комментарии типа текста перед ключом по конвенции SAP: `#XTIT`, `#XFLD`, `#XMSG`, `#XBUT`, `#YDES`.
- Кодировка UTF-8, одна пара ключ=значение на строку, без BOM.

## После правки
- `cds compile srv --to json` без предупреждений о недостающих ключах (когда ключ используется в `@title`).
- Для UI: перезапустить `npm start` и проверить экран в обеих локалях (`sap-ui-language=ru`).

## Запрещено
- Строки для пользователя в CDS, JS, XML в обход i18n.
