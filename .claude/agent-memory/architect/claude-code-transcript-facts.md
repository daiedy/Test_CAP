Facts measured on 2026-09-29 (Claude Code 2.1.282, session `6ecbd7a4` = feature #7) with narrow `jq` filters; the basis of `docs/features/pipeline-metrics/research/definitions.md` and ADR-0022 (accepted 2026-09-29; the user took all eight gate recommendations as-is: two time caps, both committed artifacts, briefing line without regression warning, explained gap instead of a 95% gate, OTel later, branch + prompt-marker join, 30-day retention, baseline #5-#7 + catalog-authorization).

- One API response = several `assistant` records sharing `requestId` (main: 287 records, 162 requests). In the main file every record of a request carries identical usage; in subagent files the usage grows with the stream (opus output: first-record sum 126K, last-record sum 227K). Rule: per request take the per-field maximum. Summing every record overcounts 1.75x.
- `message.usage` has `cache_creation.ephemeral_5m_input_tokens` / `ephemeral_1h_input_tokens` (opus in #7: 3.52M / 0.65M; sonnet all 5m), `output_tokens_details.thinking_tokens`, `iterations[]` (always one entry so far). Every record also carries `gitBranch`, `version`, `advisorModel`, `serverClassifierRequest`.
- `cost-state` is per Claude Code PROCESS, cumulative (same `startTime` = same process, totals only grow, last = process total); one process writes into several session files, one session can span several processes. Reference total = sum over distinct `startTime` of the last total. `cacheCreationInputTokens` there is not split 5m/1h. Pricing self-check (cost-state tokens x table vs its `costUSD`) is exact for sonnet, 0.2% for opus; the user made it the warning (`PRICING_TOLERANCE` 0.05) because the recovered ratio is structurally 62-97% in auto mode with subagents. `timestamp: null`; `modelUsage.<model>` has `inputTokens`, `outputTokens`, `thinkingTokens`, `cacheReadInputTokens`, `cacheCreationInputTokens`, `costUSD`; plus `totalAPIDuration`, `totalToolDuration`, `totalLinesAdded/Removed`, `hasUnknownModelCost`. Transcript recovers 75-89% of cache tokens and 35-46% of `outputTokens`; the transcript output equals `thinkingTokens` within 0.1% for opus (unexplained, hypothesis list H1-H5 in the research file). Haiku appears only in cost-state (title generation).
- Subagent meta (`agent-<id>.meta.json`): `agentType`, `description`, `requestShape` (`background`), `toolUseId`, `spawnDepth`; `<id>` = hook `agent_id` = MCP audit `agent`. Main `Agent` tool input: `subagent_type`, `description`, `prompt` (no `run_in_background`); `SendMessage.input.to` = agent id (23 resumes over 8 agents in #7).
- Corrections from phase 2 step 3 (2026-09-29): with verified 5m/1h cache-write prices the transcript recovers 73% of cost-state ($62.88 of $85.73); the prototype's 88% / $75.25 priced every write at 1h. Time: D5 (assistant + user records only) gives 152.1 main active min; the prototype's 162.3 came from `system/away_summary` (+7.9) and `queue-operation` (+2.2) splitting idle gaps. Lesson: never quote a prototype figure as a gate target before the pricing and the record filter are the plan's own.
- Resumed/forked sessions copy earlier history into their own file with the same `requestId` AND `uuid` (uuid survives the copy, timestamp almost always); a copied subagent file keeps its `agent-<id>` name. So D1 dedupes per scope, not per file, and timeline points dedupe by `uuid`. 78% of subagent requests are `stop_reason: null` snapshots only (output provisional). `gateSource` in code/history is `events` | `stop-hook-summary`. The parser's field list lives in `slim()` (+ `sessionFiles()` for meta `agentType`/`toolUseId`); definitions section 1 and the fixture's allowed keys must mirror it exactly (amended 2026-09-29 after test-backend found `version`, `subtype`, `hookErrors` emptiness, Agent block `id`, user `content` type missing); `stop_reason` is not read.
- Hooks reference (code.claude.com/docs/en/hooks.md, fetched 2026-09-29): SubagentStop also fires for Claude Code internal agents (prompt suggestions, `/btw`; empty `agent_type` without `--agent`, no transcript file, ~every 32 s during a subagent run); SubagentStart is documented only for spawned/resumed/team agents. Doc examples show `agent_id` `agent-abc123` on Start but `def456` on Stop: verify the join live. The metrics hooks skip `agent-stop`/`gate` for internal agents.
- D12 amendment (user, 2026-09-29): a launch before the first `phase` marker takes its home phase (exception to D11's phase 0) and is not live-rework.
- Sessions and features (project dir `~/.claude/projects/-Users-anton-straltsou-github-Test-CAP/`): #7 in `6ecbd7a4` only; #5 and #6 both in `0bb70a42`, #6 also in `0f92618d` (no cost-state); `catalog-authorization` in `e9ead85a` and `29ece8c2`; the 2026-09-06 session `488be2d6` ($382) spans 14 branches.
