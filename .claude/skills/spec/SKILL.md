# Спецификация: $ARGUMENTS

1. Придумай kebab-name и создай `docs/features/<name>/`.
2. Делегируй `architect` через Agent: CONTEXT.md и PLAN.md по шаблонам `templates/feature/`. Передай описание дословно.
3. Если фича затрагивает UI, делегируй `ux-designer` раздел «Экраны» в CONTEXT.md.
4. Покажи пользователю: краткое содержание плана (шаги, агенты, файлы), решения, требующие ADR, открытые вопросы, оценку риска дублирования.
5. Кода не пиши и ветку не создавай. Реализация запускается отдельно командой `/feature <name>`.
