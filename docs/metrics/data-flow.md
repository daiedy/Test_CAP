## 3. Joining live and history

`metrics.mjs` reads, per session: the event log when present (phase markers, the command markers of D10, `agent-stop` aggregates, gates) and the transcript files through `transcript-usage.mjs` (usage, timeline, the D13 turn inputs). Paths come from the `session` and `agent-stop` records when present; otherwise from `projectDir(cwd)` and the `subagents/` walk (history: #5-#7 and every session before the hooks land).

Agent figures (user decision 2026-09-29, VERIFICATION F4): the card always takes the transcript re-parse when the agent file exists. The last `agent-stop` aggregate per agent is the fallback only when the file is gone: its tokens are priced under the record's single `model` with the current table; it adds no timeline points, so lead time and the phase active time leave it out, while its own `activeMin` counts toward agent-minutes; it lacks the final request by construction (section 2); the card warns `agent-transcript-missing:<agent>`.

Drift check (a changed transcript format, independent of `cost-state`): when both exist, the live aggregate is compared with the re-parse of the same file cut at the record's `lastTs` (the file's records with `timestamp` ≤ `lastTs`, D1 applied to them); a token-sum difference above 1% (`DRIFT_MAX`) warns `agent-stop-drift:<agent>`. The uncut re-parse holds one request more than the record by construction, which is not drift: VERIFICATION check 5 found the cut re-parse equal to the live record in every kind for both agents (7 and 31 requests).

Cost of an aggregate with an unpriced model: D4 "Partial cost" (`≥$x`, `n/a`, `costPartial`, `reworkPartial`). Feature scope: D10. Phase scope: D11 with markers, home-phase fallback without; rework basis: D12's plan assignment, home-phase fallback without; both stated in the card header (`phases: markers` or `phases: home-phase fallback`; `rework: plan` or `rework: home-phase fallback`).

Fields added in fix round 1: `prompts`, `handbacks`, `notifications` (D13; `prompts` changes meaning), `reworkSource` (`plan` | `home-phase`, D12) and `costPartial` (boolean, always written; `true` only through `record --force`, D4). The 4 baseline lines of `docs/metrics/history.jsonl` are re-recorded (`record <name> --force` replaces a line, PLAN step 11c) so every line carries them; no line with the old `prompts` (every string `user` record: 27, 16, 22, 54) remains, and `compare` prints `n/a` for a field a line lacks.

`gateSource` is `events` when `gateBlocks` come from the live `gate` records of the event log and `stop-hook-summary` when only the transcript's Stop hook summaries exist (history: the Stop gate alone, no reason), so `compare` never subtracts a history count from a live one silently: the history count misses every SubagentStop and PreToolUse block.

Inputs of the non-transcript figures: `review` = list items under `## Blocking`, `## Important`, `## Minor` of `docs/features/<name>/REVIEW.md` (the reviewer's result format), `total` = all three; `criteria` = `- [x]` / `- [ ]` lines of the `## Acceptance criteria` section of `PLAN.md` via `sections()` from `doc-shapes.mjs`; `lines` = `git log --shortstat` over commits whose subject contains `<name>` (the `/feature` commit convention `feat(srv): <name> backend`); `maxTurns` from the frontmatter of `.claude/agents/<agentType>.md`; MCP figures from `readAudit` and `mcpGaps` of `mcp-audit.mjs` per agent.
