## Pending

- 2026-11-11. `context-hygiene` (#44), brief ceilings. A feature whose own brief set the ceiling of its role group sits exactly at it, so any later edit to a brief-included `CONTEXT.md` section turns `check-feature-docs` red; the `cap-backend-dev` phase 2 brief ended 38 bytes under. Status: Pending `.claude/agents/architect.md` (run `node scripts/feature-brief.mjs <name> --all` after each edit of a brief-included section and pay for added text by removing restated figures).
- 2026-11-11. `context-hygiene` (#44), orchestration. `git diff --stat` does not list untracked new files, so a coordinator took the new `resume-gate.mjs` for unchanged; and a delegation message promised "phase 2" to a type with step rows in phases 2 and 4, whose brief is the last own phase before the current one. Status: Pending `.claude/skills/feature/SKILL.md` (read `git status --short` as well as the diff stat; name the step numbers, not the phase, in a delegation message).
- 2026-11-11. `context-hygiene` (#44), test proofs. A mutation check of a rule's main branch does not cover its fallback branch ("else the highest" needs a type with two or more own phases launched before the first); a safety case behind an allow-on-error `try/catch` stays green with its guard removed (mutate the rule to deny); a fixture case for a denied tool attempt needs an error `tool_result`, a missing one proves nothing. Status: Pending `.claude/rules/tests-backend.md`; the hook-test half is in TESTING "Context-hygiene hooks".
- 2026-11-11. `context-hygiene` (#44), docs-keeper. `docs-keeper` gets a brief (every criterion) yet must open `PLAN.md` to tick the criteria, so a whole `Read` is denied once with reason `brief` and adds noise to the card's gate count; `scripts/metrics.mjs` prints in `PIPELINE_LANG`, a Russian card pasted into an English document. Status: Pending `.claude/agents/docs-keeper.md` (tick through a ranged `Read` or `sed` of `## Acceptance criteria`; run metrics with `PIPELINE_LANG=en` before quoting).
- 2026-11-03. `@sap/cds` 10.1.1 → 10.2.1 (Dependabot PR #46): `sap-messages` texts arrived with raw `{0}` placeholders in 3 tests without an `Accept-Language` header. Cause: undocumented in the changelog; `@sap/cds/lib/i18n/locale.js` of 10.2.0 returns `req.locale = undefined` for a request without a language header (the fallback to `i18n.default_language` sits behind `cds.features.locale_fallback`, "remove fallback with cds^11"), and `cds.i18n.messages.at(key, locale, args)` treats a non-string locale as its args. Fix: `messageText(key, locale, args)` in `srv/catalog-service.js` passes `locale ?? cds.i18n.default_language` (PATTERNS "Success message of an action"). Check: `npm test` 246 passed on 10.2.1 and on the merged 10.2.2. Status: Pending upstream `@sap/cds`; the change is not in the changelog or the `req.locale` docs, report it after a duplicate search (`docs/upstream/sap-reports.md`).
- 2026-10-27. `business-rules-wiki` (#28), ADR digests. A digest in `docs/wiki/decisions/` carries no stamp over its ADR (`verified` covers `code` files only), so an amendment leaves the digest stale unnoticed. Status: Pending `scripts/wiki.mjs` (a `sources` stamp written by `confirm` and checked by `audit`, a `/backlog` wish); until then the `docs-keeper` step 6 line restates the digest by hand.
