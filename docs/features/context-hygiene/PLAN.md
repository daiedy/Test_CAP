## Risks
- A hook fact fails in the probe (step 2): each fact has a fallback in `CONTEXT.md` "Probe facts"; the phase stops until the plan is amended, detected by the results file.
- The brief follows the `Feature` and `Phase` lines of `docs/STATE.md`: a launch before the orchestrator's `Phase:` edit gets the previous phase's brief. Detected by the brief header (feature, phase, step numbers) against the step numbers of the delegation message; the `/feature` rule "edit `Phase:` before launching" stays.
- A criterion marked with the wrong phase never reaches its implementer. Detected by the shape rule (a phase heading needs a step row), by `test-backend` and `docs-keeper` briefs that hold the phase's or all criteria, and by `reviewer`, who reads whole.
- A deny on `Read` confuses an agent. Soft by design (once per agent, file and content hash; the retry passes); the card counts `reread` and `brief` gates, and step 10 reads one live deny.
- The transcript format changes (2.1.310 already writes `api-request*` records next to the old kinds): the card prints the Claude Code version, the fixture encodes the shape, the key walk fails on an unknown key.
- The #28 transcripts are pruned by Claude Code about 2026-11-25 (30 days): after that the baseline is `research/context-measurements.md`, measured 2026-11-09 with the scripts kept in `research/`.
- The suite copies `scripts/` into a sandbox: agents that edit `scripts/` run one at a time and no suite runs meanwhile (`/feature` rule); steps 3, 5, 6, 7 are sequential.
