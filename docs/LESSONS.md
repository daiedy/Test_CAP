## Pending

- 2026-09-09. In FE V4 the `UI.HeaderInfo` Title/Description fallback for the editing status is **OData V2 only**, so a draft-enabled V4 List Report shows no row marker until `@Common.SemanticKey` names a `UI.LineItem` `DataField`. Source: `products-draft-marker` `CONTEXT.md` MCP #2 ("Configuring Display of Editing Status in List Report Tables"), confirmed by `products-draft-edit/VERIFICATION.md` scenarios 4/6 and re-verified in `products-draft-marker/VERIFICATION.md`. Candidate destination: PATTERNS "Drafts" row (already applied, ADR-0015).
- 2026-09-09. The semantic-key cell becomes a `sap.m.ObjectIdentifier`, and `sap.fe.test`'s `MacroFieldBuilder` matches it on its `title` property, so existing OPA5 assertions `iCheckRows({ <prop>: ... })` and `iPressRow({ <prop>: ... })` keep working unchanged after `@Common.SemanticKey` is added. Source: `products-draft-marker` `CONTEXT.md` experiment 4 (`sap/fe/test/builder/MacroFieldBuilder.js`), confirmed by all four pre-existing journeys staying green. Candidate destination: PATTERNS "Draft and lock marker in the List Report row" row (already applied, ADR-0015).
- 2026-09-09. The row draft/lock marker is asserted with `iCheckRows(values, N, { isDraft: true })` (`sap.fe.test` `TableBuilder.Row.Matchers.isDraft`); the FE marker control is `sap.m.ObjectMarker`, whose texts (`OM_DRAFT`, `OM_LOCKED_BY`, `OM_LOCKED_BY_ANOTHER_USER`) ship translated in `en` and `ru` inside `sap/m/messagebundle*.properties`, so a feature that only adds `@Common.SemanticKey` needs no project i18n key. Source: `products-draft-marker` `CONTEXT.md` experiment 4, confirmed in `VERIFICATION.md` scenario 4 (`ru` locale). Candidate destination: PATTERNS "User scenario" row (already applied, ADR-0015).
- 2026-09-09. `sap.fe.test`'s `onHeader().iNavigateByBreadcrumb('Products')` **passes without navigating** when the Breadcrumbs macro carries no links, so the failure surfaces as a timeout on the next assertion rather than on the navigation call itself. Measured cause: the breadcrumb region existed but was empty of link content while the object page was in edit mode (`nav#...--fe::Breadcrumbs` had a `sapMBreadcrumbsCurrentLocation` class but no link) — worded as measured, not as a claim that edit mode is the general reason, since that was not isolated from other possible causes. Documented fallback used in `DraftMarkerInListReportJourney.js`: `Given.iTearDownMyApp()` at the end of the case that leaves edit mode, `Given.iStartMyApp('products-display')` at the start of the next case (dialog-free, because the draft change is already persisted server-side). Candidate destination: rule `tests-ui.md`.
- 2026-09-09. Files written through `Bash` (redirection, heredoc) instead of the `Edit`/`Write` tools bypass PreToolUse `protect-files.mjs`, PostToolUse per-file-type compile/lint, and the SubagentStop edit-vs-MCP comparison — none of these hooks see a Bash tool call. Found in `products-draft-marker` phase 3 (`docs/CHANGELOG.md` 2026-09-09 "pipeline"); no protected file was actually touched that time. Needs a rule or hook change to close the blind spot, which is the user's decision because `.claude/**` and `scripts/hooks/**` are protected files themselves.
- 2026-09-09. An OPA page hang was seen once (of three otherwise-identical `npm run test:ui` runs) in the pre-existing `RussianLocaleJourney` case 2, after a successful filter search, marking the whole tail failed (9 of 23) with "Page timed out". Not reproduced on the other two runs; the project's `test:ui` script already passes `--page-timeout 900000` (the runner's own default is 0), so such a hang costs up to 15 minutes when it occurs. Source: `docs/STATE.md` "Where we are" flake note, `products-draft-marker` phase 3. No fix identified; candidate for a shorter CI page timeout.

## Pending upstream

- 2026-09-07. `run_manifest_validation` of UI5 MCP 0.2.18 fails with "schema with key or id http://json-schema.org/draft-06/schema already exists". Status: `Pending upstream @ui5/mcp-server`. Workaround in `.claude/rules/ui5-webapp.md` (ui5lint checks the manifest); `upstream-check` reports new versions.
- 2026-09-07. `sap.ushell.Container.createRenderer` is deprecated since 1.120 without a successor; the replacement is the New Sandbox (`SandboxBootTask`). Status: `Pending upstream migration`, tracked as open debt in `docs/STATE.md` (`modernize-flp-sandbox` skill, UI5 >= 1.147). The two calls carry `ui5lint-disable-next-line` with this reason.
- 2026-09-07. `fiori-mcp` `search_docs` hit an embeddings outage during `products-draft-edit`, affecting `architect`, `ux-designer` and `test-ui`. Fallback used: CDN `-dbg.js` sources of the loaded UI5 version (`sap-ui-version.json`), findings marked "not verified by MCP". Status: `Pending upstream @sap-ux/fiori-mcp-server` (pinned 1.12.2); `upstream-check` reports new versions.
- 2026-09-07. `DRAFT_ALREADY_EXISTS` and `DRAFT_ACTIVE_DELETE_FORBIDDEN_DRAFT_EXISTS` are untranslated (English) in `@sap/cds/_i18n/messages_ru.properties`, unlike `ASSERT_MANDATORY`/`ASSERT_RANGE`/`ASSERT_TARGET`, which are translated. Status: `Pending upstream @sap/cds`; not a project defect, no local patch planned.
